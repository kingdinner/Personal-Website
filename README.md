# King Rowell Vidal — Portfolio

Next.js portfolio implemented from the Stitch futuristic executive design, with details from the latest CV (airline payments, Navitaire/SkyPay, AWS, Getrosoft/AirAsia, Ascendion/Cebu Pacific, Accenture, Feemo).

## Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons
- `next/font` (Inter + Plus Jakarta Sans)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Update bio, roles, skills, and contact in `src/data/content.ts`.
Design reference lives in `design-source/`.
